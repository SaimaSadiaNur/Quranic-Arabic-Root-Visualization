# Objective-of-the-Project
This project aims to create an app or PWA that will help people to learn what the ancients Arabs used to refer to when they used a particular root word through a streak of images of gifs without the intervention of an intermediate language.
For example, showing a chest or a gateman for  ح ف ظ to depict that this particular root word is related to protecting something.
# The-scope-of-the-project
Only the root words used in the Quran
# Future-Versions
To add features like how a word acts depending on the conjugation or the format it takes.
